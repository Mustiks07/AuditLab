# Независимая сверка (verifier)

Точка входа по [INTERFACES.md](../../docs/INTERFACES.md): `auditlab.verifier.verify_snapshot(public_dir) -> list[Finding]`.
Полный машиночитаемый отчёт: `verify_report(public_dir, engine=None)`.

## Как повторить сверку, имея только public/

```sh
python -m auditlab.verifier path/to/public --out artifacts/verifier/S02.json
python -m auditlab.verifier path/to/public --engine sqlite      # без DuckDB, только stdlib
```

Отчёт содержит `findings` (формат `Finding`), `derivations` (правило, ход арифметики,
все доказательства), `notes` (нарушения целостности и неоднозначности политики),
`engine`/`engine_version`, версию правил, список SQL-файлов и `input_sha256` входных файлов.
Существующий файл отчёта не перезаписывается.

Сравнение с эталоном — отдельный доверенный шаг, который сначала записывает ответ
(`answer.json` и его SHA-256), а затем открывает truth:

```sh
python -m auditlab.verifier.crosscheck --public EP/public --truth EP/private/truth.json --out artifacts/crosscheck-EP
```

Код выхода 0 — `agree`, 1 — `disagree`. При расхождении сохраняется сокращённый
контрпример `reduced/public` + `reduced/truth.json` и команда его воспроизведения.
Редукция работает с копией: удаляет целые проводки, документы и строки курсов, пока
сигнатура расхождения не меняется. Оригинальный эпизод проверяется по хешу.

## Граница доверия

* `loader.py` — общий читатель публичной схемы: разбирает ISO-время в UTC-секунды и
  местную дату компании, суммы остаются целыми минимальными единицами, курсы — исходными
  десятичными строками. Денежных расчётов нет. Каталог `private/` отвергается.
* `sql/verifier/*.sql` — все финансовые правила. Без деления и без плавающей точки.
* `engine.py` — DuckDB (основной) или stdlib `sqlite3` (резерв). Единственный
  движковый примитив — `convert_half_up(src_minor, rate, src_exp, dst_exp)`:
  `ROUND_HALF_UP(src/10^se × rate × 10^de)` как отношение целых `floor((2N + D) / 2D)`.
  В DuckDB — SQL-макрос на HUGEINT, в SQLite — целочисленная функция Python той же формулы.
* Модули verifier не импортируют генератор, оценщик, runner, политики и `crosscheck`
  (проверяется тестом по AST и аудит-хуком открытия файлов).

## Правила (версия `verifier-rules-1.0`)

| Класс | Что считает SQL | affected_ids | Доказательства |
|---|---|---|---|
| `payment_allocation` | Остаток UNAPPLIED платежа = кредиты − дебеты по строкам строго до `policy.allocation.deadline`. При `allocation_instructions` — недозачёт по каждому счёту (инструкция − дебеты UNAPPLIED с этим счётом). | `payment/P`, `invoice/I` (единственная ссылка или счёт из инструкции) | `payments/D`, `policy/allocation`, строки UNAPPLIED до границы |
| `fx_conversion` | Для документа в иностранной валюте: ожидаемая оценка по курсу местной даты события против суммы дебетов строк в базовой валюте, ссылающихся на документ. Модуль разницы. | `payment/P` или `invoice/I` | документ, `fx/ДАТА/ИСТ/БАЗА`, `policy/fx_date`, дебетовые строки оценки |
| `period_cutoff` | Период события (дата выставления счёта / дата платежа) против периода первого отражения (первая проводка счёта в его валюте без payment_id / первая строка CASH платежа). Только пересечение границы целевого периода. Номинал в валюте документа. | `invoice/I` или `payment/P` | документ, `policy/period`, датированные строки |
| `duplicate_invoice` | Несколько документов одного `(entity_id, canonical_key)` и более одного признания: признано − один итог счёта. | счёт с самым ранним признанием (не меньший строковый ID) | все копии документа, дебетовые строки каждого признания |

Период полуоткрытый: `[period_start, period_end)`; момент 00:00 1 декабря относится к декабрю.

## Реестр неоднозначностей

| # | Где | Два разумных ответа | Что делает verifier |
|---|---|---|---|
| A1 | S02, `affected_ids` | только `payment/P9` (пример ссылки в SPEC §5) или `payment/P9` + `invoice/I4` (паспорт §6 «платёж и целевой счёт») | Ручной ответ (коммит 2fe15c3) записал `payment/P9` и пометил I4 как спорный. Verifier выдаёт оба по паспорту §6; truth подтвердил это после фиксации ответа. |
| A2 | S02, доказательства | включать ли `ledger/R7` (зачёт после границы) | Не включает: строка после границы — контекст, полноту группы доказывает `settlement_index`. |
| A3 | Местная дата | Asia/Almaty по базе tz или фиксированный сдвиг | Сдвиг берётся из `manifest.period_start` (+05:00); в офлайн stdlib Windows базы tz нет. Разные сдвиги начала и конца периода → note. |
| A4 | Структура проводок (нужно согласовать с GPT Pro 1) | — | Признание: строки с invoice_id, без payment_id, в валюте счёта. Оценка: строки в базовой валюте, ссылающиеся на иностранный документ. Денежная проводка платежа: счёт `CASH`. |
| A5 | Дубликат | общий `invoice_id` или новый ID с тем же номером поставщика | Публичное расширение `invoices[].canonical_key` (по умолчанию `invoice_id`). Без общего ключа равные суммы — чистый случай. |
| A6 | Несколько `invoice_refs` без `allocation_instructions` | целевой счёт не определён | Вывод только с `payment/P` + note. |
| A7 | Двойное признание одного документа без копии | ошибка дубликата или иной класс | Не вывод, note. |
| A8 | Отрицательные суммы при оценке (возвраты) | направление округления | Не оценивается (NULL), без вывода. |

## Тесты

* `tests/verifier/test_verifier.py` — контрольная пара против закоммиченного ручного ответа,
  границы дат (местное/UTC/иной сдвиг), четыре класса, чистые отвлекающие случаи (транши,
  возврат, равные суммы, две копии с одним признанием, платёж следующего месяца), оба
  взаимодействия в четырёх состояниях, разрядности 0/2/3 и точка округления, паритет движков,
  граница доверия, CLI.
* `tests/verifier/test_crosscheck.py` — ответ записан до чтения truth; искажения копии
  эталона по видам (валюта, сумма ×100, affected_id, неизвестная/чужая ссылка, неполный и
  слишком большой набор); редукция контрпримера.
* `tests/metamorphic/test_transforms.py` — перестановка строк + взаимно однозначная замена
  ID (обращающая строковый порядок), запись тех же моментов в UTC.

Не покрыто здесь: двойной зачёт в тестовой версии оценщика (тест награды — зона оценщика),
сгенерированные эпизоды (генератор ещё не поставлен).
