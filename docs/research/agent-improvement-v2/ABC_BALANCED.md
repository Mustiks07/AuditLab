# Открытое сравнение A/B/C с чередованием вариантов

План `abc-dev-balanced.plan.json` зафиксирован 22 ноября 2026 до его первых
API-вызовов. Он производный от `abc-dev.plan.json`, а не побайтовый повтор старого
плана с четырёхсекундной паузой. Промпты A/B/C, модель, 12 эпизодов и три повтора
не меняются: всего 108 слотов. Это подбор на dev, не окончательная закрытая оценка.

Основание изменения транспорта: в опубликованном RC5-повторении четырёхсекундная
пауза клиента съедала лимит эпизода, а выполнение всех A до B/C оставляло сравнение
без других вариантов при остановке сервиса. Теперь каждый эпизод/повтор посещает
все три варианта, циклически меняя первый. Это детерминированный порядок, независимый
от результатов. Между попытками выдерживается 60 секунд вне эпизода. Внутри эпизода
все варианты имеют одинаковую нулевую клиентскую паузу, сохраняют 60 секунд от reset,
100 действий, обработку HTTP 429/Retry-After и ограниченное число повторов запроса внутри попытки. Повторы целого слота после
сервисного сбоя отключены: один неудачный A не должен занять все три места
до остановки сервиса, не дав выполнить B/C. Это не
снимает квоты сервиса. Все попытки, включая сервисные сбои, остаются в журнале.

Лимиты бюджета и остановка после последовательных сбоев сохранены. Неизвестная
стоимость не становится нулевой. Нулевые цены конфигурации относятся к заявленному
пользователем Free Tier, платёжный аккаунт не проверяется этим экспериментом.
Паузы записываются в invocation; остановка, пришедшая во время паузы, не запускает
ещё одну попытку. Повторный запуск пропускает уже завершённые слоты.

Главные выводы делаются по независимому пересчёту сохранённых ответов, с отдельными
знаменателями отправленных ответов, тайм-аутов и сервисных ошибок. При неполном наборе
или одной семье улучшение и обобщение не объявляются. Промпты не подстраиваются
по промежуточным результатам этого запуска. Закрытые данные здесь не используются.

Для управляемой сети локальный экземпляр плана закрепляет image ID, прокси и CA;
его отдельный SHA сохраняется в квитанции. В переносимом плане нет секретов.

```sh
python -m auditlab.research.agents dry-run --plan docs/research/agent-improvement-v2/abc-dev-balanced.plan.json
python -m auditlab.research.agents run --plan docs/research/agent-improvement-v2/abc-dev-balanced.plan.json \
  --out artifacts/abc-dev-balanced --confirm-paid
```

Ключ — только в окружении контроллера. Для повторного расчёта уже сохранённых
ответов API и ключ не нужны.

Перед первыми результатами B/C отключены повторы слота после наблюдённого минутного
ограничения API на предварительном A. Предварительный запуск сохранён отдельно;
его исходы не смешиваются с новым планом. Промпты по этому исходу не менялись.
