## Основание сравнения

**Публичные конкурсные решения — не проверено.** 20.11.2026 проверены индексируемые результаты по точному русскоязычному названию задачи, `GENESIS.EXE`, датам 19–22 ноября и сочетаниям `financial audit`, `RL`, `FinTech` с GitHub, GitLab и Devpost. Карточки Stavleak и Code Union совпадают с календарём события, но не дают версий проектов или результатов закрытой проверки. RAEM датирован 11 ноября и также сообщает только о событии. В выдаче `Genesis Hackathon` встречаются другие события, например OKX.AI с июльским дедлайном и треком Finance Copilot. Я не нашёл решения другой команды с подтверждённой принадлежностью именно к этому кейсу, версией исходника и результатами на общем наборе. Закрытые каналы и неиндексируемые репозитории в охват поиска не входят. [Stavleak](https://genesis-hackathon-2026.stavleak.com/ru), [Code Union](https://code-union.com/hub/ru/kazakhstan/events/genesis-hackathon), [RAEM](https://raem.kz/konkursy-hackathony-noyabr/), [пример другого мероприятия](https://github.com/sylesh7/Sentra).

**Минимум по PDF.** Для сравнения беру гипотетическую полностью соответствующую среду. Она генерирует согласованную книгу с четырьмя управляемыми классами, двумя взаимодействиями, чистыми эпизодами и отвлекающими случаями. Она предоставляет все публичные действия `reset/step` с бюджетом 100, закрытый режим с изоляцией и один-в-один matcher с доказательствами и общей наградой. В сдаче есть лицензия, зафиксированные зависимости, схемы, четыре адаптера, 10 train + 10 dev, траектории, тесты, дизайн, одна команда проверки без сети и скриптовое демо. Финансовая состоятельность и прохождение внешнего протокола входят в этот минимум. Дополнительные свидетельства AuditLab ценны потому, что их можно повторить и проверить при разборе сбоев. [PDF, стр. 1–6](../../../case/GENESIS-FinTech-2026.pdf).

**Сильный публичный ориентир — FinRCA-Bench v1.** Первое публичное состояние 18.08.2026, `76c93ec32536e29826e2ab9e68b58e0351410bc7`, просмотрено 20.11.2026. Авторы документируют 15 детерминированно внедряемых классов ошибок в цепочке от закупки до банка, проверку чистой книги до мутации, правдоподобные чистые исключения, идентификаторы доказательств, SHA-256 канонических данных и разбиение по группам поставщиков с отдельным challenge test. Описаны раздельные срезы для обнаружения, локализации причин и доказательств. Это ориентир для качества генерации и протокола удержания семейств. Проверены публичные описание и история версии. Код и опубликованные оценки здесь не запускались. У FinRCA-Bench выходом служат задачи реконструкции причин и ответы по табличным данным, у AuditLab — пошаговое расследование с бюджетом, обязательной сдачей структурированных выводов и терминальной наградой Genesis. Результаты этих задач несопоставимы. Участие внешнего проекта в этом отборе не установлено. [README по SHA](https://github.com/PratikGhawate/FinRCA-AI-Bench/blob/76c93ec32536e29826e2ab9e68b58e0351410bc7/README.md), [история публичного выпуска](https://github.com/PratikGhawate/FinRCA-AI-Bench/commits/main/).

## Собственная проверка CLI и сравнения

На Windows использованы встроенный Python 3.12.14 и уже установленные зависимости из `../AuditLab-issue13/.venv/Lib/site-packages` через `PYTHONPATH`: DuckDB 1.1.3, FastAPI 0.115.6, tzdata 2026.6. Без установки пакетов. Команды из корня, `S01_RUN`, `S02_RUN`, `NEW_RUN` и `COPY_RUN` подставляются из `list` и JSON-ответов `change` / `rescore`:

```sh
python -B -m auditlab.demo --root artifacts/case-fit-competitive/cli samples
python -B -m auditlab.demo --root artifacts/case-fit-competitive/cli list
python -B -m auditlab.demo --root artifacts/case-fit-competitive/cli show --run S01_RUN
python -B -m auditlab.demo --root artifacts/case-fit-competitive/cli show --run S02_RUN
python -B -m auditlab.demo --root artifacts/case-fit-competitive/cli change --source S01_RUN --target ledger/R7 --value 2026-12-01T00:01:00+05:00 --prediction '20000 KZT' --op competitive-cutoff
python -B -m auditlab.demo --root artifacts/case-fit-competitive/cli rescore --source NEW_RUN --replace ledger/R5 --with ledger/R6 --op competitive-evidence
python -B -m auditlab.demo --root artifacts/case-fit-competitive/cli show --run COPY_RUN
python -B run.py replay --root artifacts/case-fit-competitive/cli --run NEW_RUN --check
```

## Что укрепить до сдачи
