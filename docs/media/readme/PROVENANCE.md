# Изображения README

`cover.png` — оригинальная иллюстрация, созданная с помощью генерации изображений для AuditLab. Это графическое оформление, не скриншот и не свидетельство измерений.

`workspace.png`, `comparison.png` и `gemini-dossier.png` — скриншоты работающего приложения с кодом `e440a15f255a72a8a7777587ac46c12519f10479`. Сняты 22 ноября 2026 года в Chromium через Playwright, viewport 1440 × 1000, device scale factor 1. Интерфейс собран через `npm ci` и `npm run build` из `web/`; Python-зависимости установлены из `requirements.lock` с проверкой хешей. При съёмке ошибок JavaScript не зарегистрировано.

Сервер запущен с новым локальным каталогом результатов и опубликованным экспортом первого пилота Gemini:

```sh
python -m auditlab.demo --root artifacts/readme-console serve --port 8876 --research docs/research/gemini/evidence/console
```

- `workspace.png`: рабочая область `/#/`, шесть подготовленных запусков.
- `comparison.png`: сравнение контрольной пары компаний A и B, открываемое из рабочей области.
- `gemini-dossier.png`: досье `/#/research/dossiers/gemini-tools--82be64bda11527df` из [сохранённого исторического пилота](../../research/gemini/README.md).

Снята видимая область настоящих страниц. Данные, тексты и DOM для снимков не подменялись; сетевые ответы не мокировались. Новых запросов к модели при подготовке изображений не было. Скриншоты показывают часть страницы; полные документы, расчёты и траектории доступны в приложении.
