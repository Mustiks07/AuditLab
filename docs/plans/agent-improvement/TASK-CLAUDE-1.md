# Промпт Claude Pro 1: настоящий агент и обучение

Адаптер/runner уже приняты. Начни отдельный worktree от актуального main,
ветка `feature/llm-auditor-experiments`. Прочитай SPEC, INTERFACES, TEAM и общий пакет.
Ты владеешь API-агентом, памятью, безопасным сетевым мостом и обучающим исполнением.

1. Реализуй provider interface и один фактически доступный API backend. Модель
   самостоятельно выбирает инструменты и submit через официальный адаптер. Публичное
   наблюдение — единственный источник эпизода; ни truth, ни oracle, ни готового решения.
2. Сделай простой вариант и вариант со структурированными заметками: подтверждённые
   факты/ссылки, непроверенные вопросы, гипотезы. Арифметика через разрешённый calculator.
   Проверка формата перед submit не должна тайно подставлять правильный финансовый ответ.
3. Записывай фактические tool calls, ошибки, финальный ответ, model ID, параметры,
   prompt hash, токены/стоимость/время. Нужны бюджет, rate-limit handling, bounded retries,
   безопасное resume и сохранение неуспешных попыток. Все повторы входят в стоимость/лимит.
4. Сетевой мост отдельный от обычного sandbox и не имеет приватных данных. Никаких
   API-ключей в коде/логах/UI. Отдельные официальные и исследовательские лимиты.
5. Реализуй обучение поддерживаемой модели: экспорт/валидация данных, dry-run,
   создание и отслеживание задания, checkpoint и повторная оценка. Выбор конкретной
   модели/провайдера подтверждается возможностями доступа, не догадкой по имени.
6. Проведи сравнение исходной модели, обучения на случайных задачах и обучения на
   адаптивном наборе с равными настройками/бюджетами. Отдельно сравни prompt/few-shot
   улучшения; не называй их обучением весов. Финальную выборку предоставляет Claude 2.

Не запускай платные запросы/обучение без настроенного лимита и доступного секрета.
Подготовь интеграцию полностью; отсутствующий доступ обозначь конкретно. Не заменяй
обучение mock-результатом. Нужны живые provider smoke test, измеренный эксперимент,
изоляционные регрессии и тесты timeout/provider failure/invalid action/budget stop.
Сохрани офлайн-запуск основного AuditLab. PR содержит SHA, команды и настоящие
артефакты, а также всё, что осталось непроверенным. Слияние выполняет интегратор.
