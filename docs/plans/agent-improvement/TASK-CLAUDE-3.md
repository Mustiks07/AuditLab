# Промпт Claude Pro 3: интерфейс исследования ИИ

После приёмки текущих исправлений и дизайна GPT Pro 1 начни отдельный worktree от
актуального main, ветка `feature/agent-research-console`. Прочитай SPEC, INTERFACES,
принятую систему C3 и общий пакет. Сохрани стиль и рабочую финансовую цепочку.

1. Добавь связный путь: выбрать агента и эксперимент → увидеть найденные слабости →
   открыть финансовый случай → посмотреть сокращённый пример → учебный набор →
   сравнение версий на новых компаниях. Подключай настоящие артефакты общего контракта.
2. Показывай документы, полученные агентом, действия, подтверждённые расчёты и итог
   оценки. Не приписывай модели внутренние мысли и психологические причины ошибки.
3. Сравнение показывает знаменатели, FP на чистых, стоимость, время, бюджет и
   неопределённость. Нулевой/отрицательный эффект и незавершённый эксперимент —
   полноценные состояния. Отсутствие данных не превращается в нулевую ошибку.
4. Для живого запуска и сохранённой траектории используй понятные разные статусы.
   Названия компаний/документов человеческие; raw ID/JSON/версии в подробностях и
   экспорте. Происхождение данных доступно в «О данных», без ложного заявления о
   подключённых реальных банках/клиентах. UI не показывает приватный ответ действующему агенту.
5. Нужны пустые состояния, отказ API, превышение бюджета, timeout, недоступная модель,
   отсутствие обучения, загрузка и несовместимый артефакт. Запуск через UI разрешён
   только при серверном бюджете и настроенном доступе; секреты не возвращаются браузеру.
6. Пройди настоящий полный путь на компьютере и телефоне, проверь клавиатуру и
   reduced motion. Сохрани реальные скриншоты. Подготовь сценарий видео до 3 минут:
   случай → действия агента → проверяемый провал → исправление/обучение → честное сравнение.

Не меняй финансовые формулы, официальные статусы и алгоритм поиска. Фикстуры для
разработки явно отделяй от измерений, не выпускай красивую страницу без подключённого
пути. PR содержит актуальный SHA, тесты, скриншоты и список непроверенного. Main сливает
интегратор после сверки с реальными артефактами.
