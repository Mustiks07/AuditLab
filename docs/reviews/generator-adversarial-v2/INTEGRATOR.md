## Дополнительная финансовая диагностика

```sh
python tools/check_generalization.py --count 1000 --output artifacts/generator-1.6-stress
```

Зафиксирована прежняя матрица `financial-stress-1.1`, seed 920001–921000,
SHA-256 отбора `f6c2a1f89d3ec9555707ba346c3590fd00365a2eaab6b357031b1688c3957cac`.
Результат: **1000/1000**, **2580 TP / 0 FP / 0 FN**, **260 полностью чистых
компаний**, **40/40 преобразованных пар**. Время этого запуска 255,565 с.
[Сводка и хеши](integrator-stress-summary.json), полный
[отчёт](integrator-stress-report.json.gz) и [отбор](integrator-stress-selection.json.gz).

Это повтор той же матрицы на новом генераторе, а не тысяча новых независимых
holdout-сценариев. Генератор 1.6 меняет данные профиля 1.1; прошлые ручные ответы
и ресурсные измерения RC3 нельзя переносить на него автоматически. Обычная
политика здесь исполняется внутри процесса: проверяются финансовая логика,
ссылки и преобразования, но не Docker-изоляция и не баллы организаторов.
Новый офлайн-кандидат потребует собственного полного прогона.
