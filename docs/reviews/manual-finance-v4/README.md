## Не проверено

- **События внутри переходного часа DST: генератор 1.4 их не порождает.** Перебор только по public/ (`scan_dst.py`, seed 1–300 на каждую зону и период): America/New_York 2026-03 и 2026-11, Europe/Berlin 2026-03 и 2026-10. Все события генератора лежат в 08:00–17:59 местного времени. Ближайшее к переходу событие — 08:00 EDT 08.03 в Нью-Йорке, через 5 часов после переключения. В днях осеннего перехода (01.11 NY, 25.10 Berlin) и весеннего в Берлине (29.03) событий нет вообще. Записанные UTC-смещения во всех просмотренных метках согласованы с зоной. Для GPT Pro 1: без отдельной настройки времени событий этот класс случаев через генерацию не проверить.
- **DAT-01: полная книга до мутаций.** В `private/provenance.json` версии 1.4 есть только агрегаты `source_book_validation` (`ledger_rows`, `document_count`, `issue_count`), полного снимка нет. Независимо проверить нечего. Пункт остаётся **«не проверено»**. Проверка интегратором через перехват книги в генераторе — его отдельное измерение.
- **Полноразмерные компании построчно вручную не разбирались.** Ответ N1/N2/N7 — вывод независимого калькулятора. Вручную проверены выборочно (взаимодействие B в N2: $257 × 2,05 = 526,85 → 527 JPY, записано 591 → 64; отсечка 25 700 USD-центов) и все половины.
- **Хронология.** Время коммита локально. Внешний свидетель — время push коммита `f30eb5a` на GitHub (12:40:05Z по локальным часам). На момент проверки Events API GitHub его ещё не проиндексировал; его стоит сверить по журналу активности репозитория. Чтение truth до push внешне не исключается; это утверждение автора.
- **Независимость.** Автор раньше писал verifier, поэтому знание его правил не исключено. Калькулятор написан заново, без копирования кода; это заявление автора.
