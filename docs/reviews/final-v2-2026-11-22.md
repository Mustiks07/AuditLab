## Исправления при интеграции

Смешанный ответ с правильными и ошибочными выводами больше не получает выдуманную
общую причину ошибки. Причина берётся из диагностики конкретного вывода; при её
отсутствии интерфейс честно пишет, что причина не установлена. Некорректные вложенные
типы ответа не обрушивают диагностику. Новые варианты профиля 1.2 связаны с лабораторией:
граница периода, сумма и взаимодействие нарушений доступны по фактическим артефактам.
Экспорт проверяет хеши исходного снимка и независимой квитанции, запрещает sealed-разделы
и выход путей за корень. Изменений зависимостей и публичного SDK нет.

Опубликованный пилот Gemini пересчитан тем же независимым скорером: три HTTP 429
остаются в знаменателе завершения, но исключены из качества модели. У варианта с
памятью нет завершённых ответов, поэтому качество **null**, а не нулевой F1.
У варианта без памяти один завершённый ответ, один пропуск, F1=0. Новых запросов
к модели эта приёмка не выполняла. У 10 прежних dev-эпизодов девять экономических
истоков; группировка исследования исправлена по происхождению.

## Воспроизведение лаборатории из checkout

Python 3.11.14, зависимости из lock с хешами; Docker нужен для изолированной полной
приёмки. Следующие команды исследования используют локальные политики и не требуют API.
Из корня чистого checkout кандидата, с новыми выходными каталогами:

```sh
python -m pip install --require-hashes -r requirements.lock
git clone https://github.com/Mustiks07/AuditLab.git ../AuditLab-reviewer
git -C ../AuditLab-reviewer checkout 85ac6c81ff9b39710e9753c7a5bc38fe2897ae82
python -m auditlab.research.curriculum.v2 \
  --plan docs/research/financial-families-v2/plan.json \
  --reviewer ../AuditLab-reviewer --output artifacts/families-v2
python tools/financial_lab_rehearsal.py \
  --search artifacts/families-v2 --output artifacts/lab-v2
python -m auditlab.demo --root artifacts/lab-view serve --port 8765 \
  --research artifacts/lab-v2/console-families \
  --research artifacts/lab-v2/console-runs
```

Открыть `http://127.0.0.1:8765/#/research`. Собранный интерфейс включён в checkout;
для изменения frontend: `npm --prefix web ci && npm --prefix web run build`.
Полная локальная приёмка правил: `python review/genesis_acceptance/run.py --output artifacts/official-acceptance`.
