# Независимая ручная финансовая проверка

Материалы переданы владельцем проекта и опубликованы автором проверки в
[обсуждении PR #8](https://github.com/Mustiks07/AuditLab/pull/8#issuecomment-7015776959).
Они относятся к указанным в отчёте старым SHA и открытым train/dev профиля 1.0.
Их нельзя выдавать за проверку новых компаний профиля 1.1 или закрытого набора жюри.

Интегратор прочитал четыре файла и подтвердил SHA-256 исходного ручного отчёта:
`33fcd7cffa08921a5599e57a0a0c68d0612fb6713e91b1a1873c8ff338b03657`.
Хеш подтверждает идентичность полученного файла. Порядок «расчёт до открытия truth»
заявлен независимым проверяющим; один хеш сам по себе не доказывает хронологию.

Результат автора: шесть финансовых находок совпали; отдельная операция возврата
чиста, хотя компания содержит другую FX-ошибку. Все 78 пар «эпизод, evidence»
доступны. Три замечания по метаданным и покрытию сохранены в notes-for-integrator.txt.
Исходные файлы сохранены без редактирования.
