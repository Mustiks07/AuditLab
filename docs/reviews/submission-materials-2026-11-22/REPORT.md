## Уточнения к обзору

**A1.** Зонд рецензента воспроизведён: 0/5 при буквальном переименовании. Он оставляет
старые составные ссылки truth и вложенные ссылки индекса. Официальные определения
требуют согласованной замены всех ссылок, включая дополнительные документированные
поля. Поэтому результат показывает риск несовместимой процедуры, а не установленную
потерю 11,25 балла. Формат не менялся; инструкция задаёт полную карту и checker.

**A2.** Без секретного `episode_key` защита от перебора небольшого пространства seed
не заявляется. Новый helper создаёт случайный ключ в отдельном файле, без вывода его
значения, с правами 0600 на POSIX и отказом перезаписать существующий файл. Входы
генератора остаются явными: скрытый машинный ключ автоматически не добавляется.
Для закрытой генерации жюри должно использовать сохранённую приватную конфигурацию.

**A3/A4.** Траектории и выбор открытого набора исправлены. Формат содержит ровно семь
полей; step 0 фиксирует reset, последующие строки — реальные step и их результаты.
Значения train-награды доступны; закрытых полей в observation нет. Oracle не использовался.

**A5.** У обычного `run.py verify` успешный код 0 совместим со статусом полной матрицы
`incomplete`. Код 2 требует строгого режима (`--require-complete` или rehearsal).
Обзор смешал статус и код выхода. Инструкция теперь объясняет их отдельно.

**B1.** Повторены все мутационные проверки на 10 train `open-1.3`:
исходный оценщик совпал с независимым эталоном в 299/299 случаях. Все Y1–Y6
обнаруживаются тестами проекта. У пяти из них поле `status=survived` относится
только к отдельной батарее атак; `project_tests_killed=true` записывается отдельно.
Эти два результата нельзя сводить к утверждению «пять ошибок тестами не ловятся».
Тесты 30/31, 1000/1001, 11 доказательств и словарного допуска уже были на базе;
новые тесты дополнили их границей 10 и диагностикой дубля.

## Воспроизведение

```sh
python tools/export_trajectories.py check
python tools/export_trajectories.py export --policy-image YOUR_LOCAL_POLICY_IMAGE --output artifacts/open-trajectories
python -m unittest discover -s tests/evaluator -v
python -m unittest discover -s tests/runner -p test_submission_materials.py -v
python review/agent_generalization/mutation_testing.py datasets/open-1.3/train artifacts/mutation-review
```

Для теста повторного Docker-экспорта задайте `AUDITLAB_POLICY_IMAGE`. Без него этот
тест явно пропускается; в CI образ обязателен. Мутационный инструмент создаёт копии
кода и дополнительные синтетические фикстуры; они не входят в опубликованный набор.
Финансовое ядро, генератор, адаптер и matcher не изменены. A/B/C и новые вызовы моделей
не запускались; внешний стенд и результат конкурса этим изменением не измеряются.
