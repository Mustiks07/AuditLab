человеческих названий, пояснения F1 для пустого чистого ответа и видимых изменений

в open_sets. Проверка конечности теперь вызывается только для float; большие int
отклоняются проверкой диапазона без преобразования в float. Добавлена регрессия для
обоих знаков, обновлена идентичная встроенная копия HANDOFF.

Сообщение run.py больше не утверждает, что адаптер отсутствует. Статус внешней
приёмки остаётся not_checked: локальный прогон не заменяет запуск организаторов.
