## Что подтверждают артефакты

- **Целостность ответа.** Опубликованный ответ — ровно тот файл, хеш которого записан в `e09d4aa`. Bundle позволяет любому восстановить этот коммит и сверить содержимое.
- **Воспроизводимость эпизодов.** Повторная генерация по `configs.json` на 461a11e дала все 80 файлов побайтно (новое измерение). Значит, каждое число в ответе можно пересчитать заново по тем же public/ и truth.
- **Нечувствительность к версии генератора.** Для этих десяти конфигураций генератор 1.4 на a301b16 даёт побайтно те же `public/*` и `truth.json`. Отличается только `private/provenance.json`: версия `1.4` и новые агрегаты `source_book_validation`. Это измерено, а не перенесено из 1.3.
- **Проверяемость сравнения.** `compare.py` и его вывод позволяют пересчитать совпадения 15/15, покрытие наборов доказательств и выдачу 54 ссылок.

## Чего артефакты доказать не позволяют

- **Хронологию.** Время коммита и время в файле хешей — локальные утверждения. Git не удостоверяет время независимо. Что ответ записан до первого чтения `truth.json`, подтверждают только заявление автора и порядок коммитов, но не внешний свидетель. Хеш не был опубликован вовне до открытия truth.
- **Что truth не читался ранее.** Файлы `private/` лежали на той же машине; изоляцию чтения ничто не фиксировало.
- **Полноту независимости.** Ответ посчитан вручную, но автор раньше написал verifier и оценщик-review, так что знание их правил не исключено. Код генератора и verifier для ответа не вызывался; это тоже заявление, а не измерение.
- **DAT-01.** Полная исходная книга до мутаций в эпизодах отсутствует. Сверены только поля `before` из `provenance.json`. Пункт остаётся **«не проверено»**.
- **Покрытие.** Малые компании (4–28 строк), один seed на сценарий, нет точной половины округления, нет событий внутри переходного часа DST. Полноразмерные компании и точная половина дополнительно проверены в v4; события внутри переходного часа DST там также остались непроверенными.
