# Проверка читаемости доказательств

Исправление интегрировано коммитом `439aee6`; точные исходники и поставляемые assets
привязаны к [хешам](source-hashes.json). Chromium проверил реальную страницу
расследования на 1440 и 1024 px. Все восемь строк доказательств и их дочерние
элементы находятся внутри панели; страница не переполняется по горизонтали.
Полный ID сохраняется в тексте и tooltip, клик открывает соответствующий документ.

На 1440 таблица расчёта шириной 640 px помещена в область прокрутки 394 px;
клавиша ArrowRight сдвинула её на 40 px. На 1024 адаптивная компоновка даёт таблице
908 px, и прокрутка не нужна. Ошибок JavaScript не зарегистрировано.

- [Экран 1440](demo-layout-1440.png)
- [Экран 1024](demo-layout-1024.png)
- [Фактические DOM-измерения](demo-layout-check.json)

Проверены 17 Python-тестов консоли, 2 frontend-теста, TypeScript и Vite build.
Это автоматическая браузерная проверка; она не закрывает приёмку новым человеком.
Для повторения: `python run.py demo`, открыть сгенерированную компанию, выбрать
доказательство в правой колонке и проверить размеры окна 1440/1024 и прокрутку
таблицы с клавиатуры.
