## Одна команда

```sh
python review/genesis_acceptance/run.py --output artifacts/genesis-acceptance            # всё, кроме 61-секундного C18 при --skip-slow
python review/genesis_acceptance/run.py --output DIR --adapter path/to/judge_adapter.py   # тот же набор для PR адаптера
python -m unittest discover -s tests/genesis_acceptance -v                              # самопроверка эталона по опубликованным значениям
```

Результат — `DIR/report.json` (полный отчёт этого прогона: [report.json](report.json)). Код возврата 0 означает, что прогон завершён; `failed` — это находки, а не авария.

## Как устроена независимость

- **Ожидания** — опубликованные значения. Каждое заново выведено рациональной арифметикой (`reference.reward_from`) и проверено моим эталонным matcher (`reference.py`). Он написан по «Точным соглашениям matcher», без импорта `auditlab.evaluator`:
  - структура и лимиты проверяются до удаления повторов;
  - ID и валюта сравниваются точно;
  - каждый evidence_id должен существовать в публичных данных эпизода;
  - τ задаётся явно;
  - максимальное паросочетание с официальным правилом выбора при равенстве.
- **Matcher проекта** — проверяемый объект, а не эталон. Все опубликованные значения совпали с моим расчётом и эталоном (`expectation_checks`: 0 расхождений).
- **Данные** — мой калькулятор `independent_calc.py` (тот же, что в v5). Ответ по public/ зафиксирован **до** открытия truth и опубликован коммитом `08810fe`: [answers_before_truth.json](answers_before_truth.json), SHA-256 `d7dd79b08f435bd5911c728eed0b6cf8747d531eb3fab82ee56db15415bfeecf`. Штатный verifier запущен отдельно и служит лишь дополнительной сверкой.
- **Пары** — моё преобразование на стороне проверяющего:
  - отдельная карта для каждого пространства ID;
  - null, деньги, порядок `line_items` и `invoice_refs` сохранены;
  - FX-ключи не меняются;
  - исходный каталог не перезаписывается.

## Замечания интегратору (минимальные примеры)

| # | Где | Вход | Ожидается | Фактически | Статус |
|---|---|---|---|---|---|
| 1 | evaluator | M-фикстура, правильный вывод + `evidence_ids=["payments/DP1","ledger/R4","ledger/R404"]` (R404 отсутствует). Также S02 + `payments/DOES_NOT_EXIST` (probe интегратора). | FP=1, FN=1, return −1 | TP=1, FP=0, return 0.98 | воспроизведено, известно интегратору |
| 2 | evaluator | правильный вывод с `type="not_a_known_type"` | несопоставимый вывод: FP=1, FN=1 | `invalid_submission`/`bad_type`, весь submit −1 | воспроизведено |
| 3 | matcher | `_max_matching([[0,1],[0,1]], 2)` | владельцы A,B = `[0,1]` (A→F0, B→F1) | `[1,0]` | воспроизведено. M10 проходит. |
| 4 | runner | Фальшивые часы: `session_opener` внутри `reset` тратит 61 с, затем один шаг (`security_checks.deadline_origin`) | `truncated=true`: 60 с от начала reset | `truncated=false`, `remaining_steps=99` | **новое**. `_started` ставится после генерации, загрузки, `validate_truth` и открытия сессии. Реальный reset на 2000 строк длится 0,012 с, поэтому практический риск мал, но правило не соблюдено. |
| 5 | генератор (GPT Pro 1) | D09–D11 требуют хотя бы один **пропуск**: назначенный платёж не зачтён совсем | документированная настройка, дающая полный пропуск | профиль 1.1 даёт только частичный зачёт: 3/5, либо остаток после или ровно на границе | **новое** |
| 6 | интерфейс | M08: τ=1 для отдельной фикстуры | публично заданный τ по типу (policy или документация matcher) | `evaluate(..., tolerance_minor)` есть, но опубликованного τ по типу нет; через `score_episode` не проверить | not_checked, нужна договорённость |

## Не проверено

- **На `main` без адаптера:** C01–C20 и официальный слой R/M/X — `not_checked`. На PR #37 (`f9a0ea6`) всё это выполнено (см. выше). Если в PR появятся новые коммиты, нужен повторный прогон.
- **Время и ресурсы машины жюри:** C18 проверен на этой машине (Windows, без контейнера).
- **Изоляция процесса политики** (контейнер, отдельный процесс): здесь только наблюдения внутреннего закрытого режима. Удачный прогон не доказывает изоляцию.
- **Политики организаторов:** их кода нет. Используется локальная политика `reconcile` и oracle из truth как аналоги.
- **Скрытые seed и конкретные значения жюри** неизвестны; данные D — мои конфигурации для каждого опубликованного смысла сценария.
