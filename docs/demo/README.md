# Консоль жюри AuditLab

Локальная консоль для открытых завершённых прогонов: шаги аудитора, документы, суммы, доказательства, вердикт, сравнение пары и повтор. Работает офлайн: собранный фронтенд лежит в `auditlab/demo/static/`, Node для запуска не нужен, внешних шрифтов, CDN и сетевых запросов нет. Официальный тестовый запуск от веб-сервера не зависит.

## Запуск

Из корня репозитория, Python 3.11:

```sh
pip install -r web/requirements-demo.txt      # fastapi, uvicorn (один раз; httpx нужен только тестам)
python -m auditlab.demo serve                  # http://127.0.0.1:8765/
```

При первом старте строятся четыре **учебных экспорта** (метка «УЧЕБНЫЙ ЭКСПОРТ») из открытой пары `fixtures/foundation/S01`, `S02` и ручного примера `auditlab/demo/scenarios/FX01`. Рабочий каталог — `runs/demo/` (в .gitignore), переопределяется `--root` или `AUDITLAB_DEMO_ROOT`.

Подключить настоящий экспорт раннера (только для чтения, принимаются только `mode: "train"` без `private/`):

```sh
python -m auditlab.demo --exports runs/exports serve
```

## Резервный показ без браузера

Те же данные, суммы и вердикты, что в UI (`show --json` выдаёт ровно ответ `GET /demo/runs/{id}`, это проверяет тест):

```sh
python -m auditlab.demo list
python -m auditlab.demo show --run TRAIN-S02-reconcile
python -m auditlab.demo change --source TRAIN-FX01-reconcile --target payments/D9 --value 2026-11-15T00:01:00+05:00
python -m auditlab.demo show --run LIVE-XXXXXXXX
python -m auditlab.demo rescore --source LIVE-XXXXXXXX --replace fx/2026-11-15/USD/KZT --with fx/2026-11-14/USD/KZT
python -m auditlab.demo replay --run TRAIN-S02-reconcile --check
```

Ошибка запуска опыта возвращает код и сообщение, например `no_rate_for_date` при сдвиге платежа на дату без опубликованного курса.

## Экраны

| Экран | Что видно |
|---|---|
| Запуски `#/` | Компания, период, политика, статус, метка, награда, связи «исходная → опыт/копия». Оборванная попытка: причина и доступность журнала. Пустое состояние с командой запуска. |
| Расследование `#/runs/{id}` | Слева шаги, в центре конкретная строка файла (`public/ledger.csv · строка 6`) с подсветкой поля-операнда, справа вывод: сумма агента → операнды → правило; строки «Агент», «Оценщик», «Консоль», «SQL» подписаны раздельно. Пустая сдача: «Ошибок не заявлено». |
| Сравнение `#/compare/{a}/{b}` | Изменённый факт, прогноз судьи, фактическая разница, обе суммы с операндами, оба ответа и оценки, построчные различия документов. Для копии сдачи — какой операнд больше не подтверждён. |
| Повтор `#/runs/{id}/replay` | «ПОВТОР ЗАПИСИ»: пошаговое воспроизведение журнала; кнопка повторяет действия на снимке и пересчитывает оценку. |

Скриншоты: [docs/demo/screenshots](screenshots).

## Сценарий защиты, 90–120 секунд

Подготовка: `python -m auditlab.demo serve`, открыть `http://127.0.0.1:8765/`. Все суммы синтетические.

| Время | Действие судьи | Что показывает консоль |
|---|---|---|
| 0–20 с | Открывает «Компания FX01 · платёж 100 USD» → «Расследование». Нажимает шаг 2 `get_document D9`, затем шаг 4 `fx/2026-11-14` | Строка `payments.jsonl:1`: 100 USD, 14.11 23:59; строка `fx.csv:3`: 500. Калькулятор аудитора на шаге 6: 10000/100×500×100 − 5000000 = 0. Справа «Ошибок не заявлено», консоль: расхождений нет. Награда 0,988 при 6 инспекциях. |
| 20–50 с | На записи `payments/D9` нажимает «Изменить факт…», ставит `2026-11-15T00:01:00+05:00`, вписывает прогноз «1 000 ₸», запускает | Ожидание → готово. Новая компания `FX01-L…` с перенесёнными `payments/D9`, `ledger/R3`, `ledger/R4` и прежней суммой 50 000 ₸. Сравнение: Δ = 1 000,00 ₸ (100 000 мин. ед.), по курсу 510 нужно 51 000 ₸. Аудитор заново прошёл компанию и заявил 1 000 ₸, оценщик засчитал. Исходная попытка не изменилась. |
| 50–80 с | «Открыть расследование» нового опыта → нажимает сумму 1 000 ₸ → `fx/2026-11-15/USD/KZT`. Затем «Заменить доказательство в копии сдачи»: `fx/2026-11-15` → `fx/2026-11-14` | Строка `fx.csv:4` (510). Копия `COPY-…`: TP 1 → 0, награда 0,988 → −1, «доказательства неполные»; жёлтая плашка: «больше не подтверждено: курс USD/KZT на 2026-11-15: 510». |
| 80–120 с | Открывает `TRAIN-S02-reconcile` → «Повтор опыта» → «Повторить действия и оценку». Для полноты — пара S01/S02 «Сравнить пару» | ПОВТОР ЗАПИСИ: 6 инспекций повторены, наблюдения и награда совпали. Пара: зачёт R7 до/после границы, остаток 0 против 20 000 ₸. При отказе браузера те же шаги — командами из раздела выше. |

## Что дал какой модуль

На строке «движок» каждой попытки указано, кто дал результат. Пока ветки других участников не слиты, среда, политика `reconcile`, оценщик и генератор изменённой компании — **учебные замены** из `auditlab/demo/standin.py` (метка «учебная замена»). `auditlab/demo/engines.py` автоматически берёт `auditlab.environment.open_session`, `auditlab.policies.make_policy`, `auditlab.evaluator.score_submission`, `auditlab.verifier.verify_snapshot`, как только они появятся в main. Строка «SQL» до слияния сверки показывает «не подключена».

## Граница доступа

- Веб-процесс (`server.py`, `service.py`, `store.py`, `snapshot.py`) читает только каталоги экспортов и статусы операций; тест запрещает в этих модулях обращения к эталону.
- Экспорт закрытого режима и экспорт с каталогом `private/` в консоль не попадают.
- Новые опыты, копии сдачи и повторная оценка выполняет доверенный процесс `python -m auditlab.demo.lab` с учебным эталоном в `runs/demo/trusted/`. Публикация — атомарное переименование готового каталога; существующая попытка не перезаписывается; тот же ключ операции возвращает тот же опыт.

## Формат экспорта

Образец: [sample_export/TRAIN-S02-reconcile](sample_export/TRAIN-S02-reconcile). Обязательные файлы — по INTERFACES.md: `run.json` (run_id, episode_id, policy, mode, status), `public/`, `trajectories.jsonl` (§11), `submission.json`, `score.json`. Необязательные, которые консоль использует при наличии: `run.json.label/company/period/engine/parent_run_id/change/derived_from/reason/journal_available`, `score.json.per_finding[{index, matched, reason}]`, `verifier.json`.

## Разработка фронтенда

```sh
npm --prefix web ci
npm --prefix web run dev       # Vite с прокси /demo → 127.0.0.1:8765
npm --prefix web run build     # tsc + сборка в auditlab/demo/static
python -m unittest discover -s tests/demo -v
```
