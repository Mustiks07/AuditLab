# Финансовая лаборатория консоли

Раздел «Исследование → Финансовая лаборатория» (`#/research/lab`) проводит пользователя по сценарию:
**понять финансовую задачу → изменить допустимый факт → проверить ответ агента по документам.**
Всё работает поверх опубликованных артефактов исследований, без ключа и без сети.

## Экраны

| Экран | Адрес | Что показывает |
|---|---|---|
| Лаборатория | `#/research/lab` | Компании с вариантами, сохранённые прогоны, вход в карту результатов |
| Связанные ситуации | `#/research/families/<компания>[/v/<вариант>]` | Задача простыми словами; пять слотов допустимых изменений; таблица «было → стало»; ожидаемый правильный ответ; независимый расчёт; ответы агентов; документы по точному ключу |
| Досье ошибки | `#/research/dossiers/<попытка>` | Правильный вывод и его источник, ответ агента, арифметика, нужные и полученные документы, наблюдаемые действия, повторы, другие агенты, сокращённый случай, исправленный контроль |
| Карта результатов | `#/research/map` | Измерения: тип нарушения, взаимодействие, чистые контрпримеры, валюты, граница периода, сложность, преобразование. Ячейка — семейства и попытки, открывает конкретные попытки. «До и после» показывает регрессии |

## Допустимые изменения: что реально есть в бэкенде

Варианты строит `auditlab.research.curriculum.families.boundary_variants`, проверяет независимый
расчёт (`IndependentValidator`), сверяет с ожиданием `answers_match`.

| Слот интерфейса | Вариант бэкенда | Ожидаемое изменение ответа |
|---|---|---|
| Переименование документов | `id_order` | ответ прежний (20 000 ₸) |
| Законная отвлекающая операция | `lawful_refund` | ответ прежний: возврат депозита законен |
| Исправление нарушения | `fixed` (транш до исключающей границы) | вывод исчезает |
| Изменение суммы и валюты | `currency` (договор в JPY, разрядность 0) | 2 000 000 тиын KZT → 20 000 JPY |
| Граница периода | — | **недоступно здесь.** Контроллер исследований не меняет факты. Ближайший вариант — «Исправление нарушения»: транш переходит через границу. Перенос «ровно на границу» выполняет генератор в разделе «Сравнения» (`POST /demo/pairs`) |

Слот без артефакта показан как недоступный, с причиной. Кнопок, которые изображали бы запуск,
нет. Выбор слота открывает сохранённый результат.

## Откуда берутся числа

Браузер не пересчитывает финансовую истину и не правит JSON документов.

- **Правильный вывод** берётся из опубликованной независимой проверки (`validation`): расчёт
  делается до открытия эталона. Если проверки нет, используется расчёт консоли по публичным
  документам (`derive`); он покрывает только остаток платежа и курсовую оценку, и экран так и пишет.
- **Исход попытки** определяется так. Счётчики оценщика (TP/FP/FN) сопоставляются с правильным
  выводом по типу и затронутому платежу или счёту:
  - *пропуск*;
  - *ложное обвинение*;
  - *неверная сумма* (тип и объект совпали, сумма или валюта нет);
  - *неверные доказательства* (тип и сумма совпали, оценщик не принял);
  - *технический сбой* (попытка не завершена: оценки нет).

  Класс считает сервер (`auditlab/demo/research_lab.py`).
- **Компания** привязывается к попытке по содержимому шести публичных файлов, а не по путям.
- **«Не проверено»**: попыток нет или повторы не измерены. Это не ноль ошибок.

## Данные и воспроизведение

```sh
python -m pip install --require-hashes -r requirements.lock
```

```sh
python tools/research_rehearsal.py --output artifacts/research-rehearsal
```

```sh
python tools/financial_lab_rehearsal.py --search artifacts/research-rehearsal/search --output artifacts/financial-lab
```

```sh
python -m auditlab.demo --root artifacts/lab-console serve --port 8765 \
  --research artifacts/financial-lab/console-families --research artifacts/financial-lab/console-runs \
  --research docs/research/gemini/evidence/console --research artifacts/research-rehearsal/console-search
```

Второй шаг публикует все открытые train/dev-компании поиска и восемь вариантов двух пар как
артефакты `candidate` (`python -m auditlab.research publish-families`). Затем на этих 25 компаниях
настоящий раннер и оценщик запускают четыре встроенные политики: пустой ответ, случайные выводы,
«обвинить всё», сверку. Это 100 попыток, без сети и без вызовов модели. **Встроенные политики — не
ИИ-модели.** Они нужны, чтобы у каждого варианта был настоящий измеренный ответ агента. Закрытые
разделы (`test`, holdout) не читаются и не экспортируются.

Сохранённый живой пилот Gemini (`docs/research/gemini/evidence/console`) входит в карту и досье так,
как он был измерен:
- одна завершённая попытка — пропуск остатка 30 240 ₸;
- три попытки — HTTP 429 у провайдера.

Сравнения вариантов нет: экран сравнения показывает незавершённость, а «до/после» для этих вариантов —
«нельзя сравнить».
