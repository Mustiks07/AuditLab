# Claude Pro 3 — Консоль жюри, воспроизведение расследования и демо

Ветка `feature/judge-console`. База и цель PR — `main`.

**Вход.** Прочитать [ТЗ](../SPEC.md) §§11, 13–15, 17 и [контракты](../INTERFACES.md). Запустить `python -m unittest discover -s tests/foundation -v`.

**Владение.** web/, auditlab/demo/, tests/demo/, docs/demo/.

## Задачи

1. Поставить локальную консоль FastAPI + React/TypeScript/Vite для открытых завершённых прогонов: шаги, документы, суммы, доказательства, сверка и сравнение пары.
2. Для первой итерации использовать явно помеченный пример экспорта; затем читать настоящий журнал Claude Pro 1. Изменение факта запускает реальный новый опыт через доверенный сервис и создаёт отдельный run_id.
3. Собрать статические ресурсы для офлайн-показа, краткую инструкцию и сценарий на 90–120 секунд. Предусмотреть ошибку запуска, пустой результат и резервный повтор через CLI.
4. Веб-сервис читает только разрешённые открытые экспорты и связывает поля с исходными документами; официальный тестовый запуск не должен зависеть от веб-сервера.

## Приёмка

На двух открытых компаниях судья меняет один факт, видит доказуемую разницу, открывает документы и повторяет расчёт. Сырые закрытые прогоны через UI недоступны.

В PR укажи команду воспроизведения, пройденные и непройденные проверки, влияние на контракт и зависимости. Свяжи PR со своей GitHub Issue, если она опубликована. Открывай PR в main. Итоговое слияние выполняет GPT Pro 2 после проверки.
