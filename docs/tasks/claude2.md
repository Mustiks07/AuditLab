# Claude Pro 2 — Независимая финансовая сверка и парные испытания

Ветка `feature/independent-verifier`. База и цель PR — `main`.

**Вход.** Прочитать [ТЗ](../SPEC.md) §§4–6, 10–12, 14 и [контракты](../INTERFACES.md). Запустить `python -m unittest discover -s tests/foundation -v`.

**Владение.** auditlab/verifier/, tests/verifier/, tests/metamorphic/, sql/.

## Задачи

1. Зафиксировать ручные расчёты по публичной финансовой политике. Написать независимую сверку на DuckDB/SQL для четырёх классов и двух взаимодействий.
2. Проверить обе стороны контрольной пары, границы валют и дат, полные наборы доказательств, корректные платежи без ошибок и корпоративные периоды.
3. Реализовать проверки перестановки и смены ID, контролируемые искажения тестовых копий; отдать интегратору машиночитаемый отчёт по эпизоду и способ повторить расхождение.
4. Сверять свой расчёт с truth отдельным тестовым шагом после фиксации своего ответа. Реализация verifier импортирует только публичные схемы, а не генератор, scorer или приватный каталог.

## Приёмка

Модулю достаточно только public/. Пересчёты совпадают с ручными примерами; изменённая сумма в копии эталона обнаруживается при сравнении, независимый ответ сохраняется при переименовании.

В PR укажи команду воспроизведения, пройденные и непройденные проверки, влияние на контракт и зависимости. Свяжи PR со своей GitHub Issue, если она опубликована. Открывай PR в main. Итоговое слияние выполняет GPT Pro 2 после проверки.
