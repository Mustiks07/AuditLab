# Приёмка реализации C3

Этот список относится к будущему PR GPT Pro 1. Проверка HTML-образца в пакете не заменяет проверку приложения.

## Команды из корня свежего checkout

Использовать зафиксированную версию Python/Node и lock-файлы репозитория. Установку Python брать из актуального README (включая --require-hashes для requirements.lock); новые версии зависимостей без необходимости не выбирать.

```sh
npm --prefix web ci
npm --prefix web test
npm --prefix web run typecheck
npm --prefix web run build
python -m unittest discover -s tests/foundation -v
python -m unittest discover -s tests/demo -v
python -m auditlab.demo samples
python -m auditlab.demo serve --host 127.0.0.1 --port 8765
```

Уточнить актуальное место сборки в vite.config: приложение отдаёт `auditlab/demo/static`, а не произвольную папку web/dist. Не коммитить generated artifacts вопреки существующему .gitignore. Если есть изменения упаковки/ресурсов, прогнать соответствующие release checks и проверить попадание локальных шрифтов в offline-сборку. В CI дождаться всех требуемых checks актуального HEAD.

## Функционально

- [ ] Реальные экспорты открываются с домашнего экрана; прямые старые ссылки не сломаны.
- [ ] Открыть запуск, поиск, комбинированные фильтры, очистка, выбор строки, «все запуски» работают.
- [ ] При смене выбранного запуска старый медленный ответ не перезаписывает новый.
- [ ] Карточка продолжения восстанавливается после reload и переживает удаление экспорта.
- [ ] Сравнение ведёт к настоящей паре; A/B и направление разности не перепутаны; случайная пара не объявлена отличающейся одним фактом.
- [ ] Документ ведёт к тому же ключу; детали запуска → документ → назад сохраняют контекст.
- [ ] Повтор, изменение факта и пересчёт работают как раньше, оригинал не меняется.
- [ ] Сохранённое содержит настоящие ссылки и сохраняется локально; нет фальшивой серверной синхронизации.
- [ ] Нет внешних запросов к шрифтам/CDN/аналитике; после загрузки локального сервиса интернет не требуется.

## Данные и язык — meaningful tests

- [ ] completed не превращается в «независимо подтверждено».
- [ ] missing verifier/derivation/currency, null findings/reward, сбой и усечение не рисуют ложный успех.
- [ ] Проверены JPY/KWD/KZT, отрицательная/нулевая сумма, большие числа и отсутствие разрядности.
- [ ] Для нескольких выводов показывается выбранный, а не необоснованная сумма разных валют.
- [ ] Все обычные экраны и ошибки используют человеческие названия; raw code/path/hex ID и `reconcile` не торчат в тексте, tooltip и aria-label.
- [ ] Служебные «демо»/«синтетические данные» отсутствуют в обычной навигации/баннерах; происхождение доступно в «О данных».
- [ ] Словарь известных примеров не применяется к неизвестным компаниям по случайному совпадению ID; alias не ломает маршруты.
- [ ] Закрытые данные не стали доступны из-за нового списка/поиска/документов.

## Визуально и доступность

- [ ] Реально открыть браузер на 1440×960, 1280×800, 390×844; дополнительно проверить отсутствие переполнения при 320 px и zoom 200%.
- [ ] Один основной скриншот home сравнить рядом с C3/HTML: сетка, масштаб заголовка/суммы, плотность таблицы, поля, выбранная строка, иконки.
- [ ] Отдельно проверить длинные названия, много строк, пустой список, загрузку, отсутствие совпадений, 404 документа, API error, unknown verification.
- [ ] Все действия достижимы Tab; Ctrl/Cmd+K, Escape, диалог и возврат фокуса работают. Никаких click-only div.
- [ ] Цвет дополнен текстом, контраст WCAG AA, активный пункт aria-current, таблица/список семантичны.
- [ ] prefers-reduced-motion отключает перемещения; hover не меняет размер элементов.
- [ ] В web console нет ошибок, отсутствующих assets, неуспешных загрузок шрифтов.
