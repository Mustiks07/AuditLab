# AuditLab C3 — пакет передачи дизайна GPT Pro 1

Пользователь выбрал светлое направление C и одобрил отдельный главный экран C3. Это задание на реализацию рабочего продукта. Последнее уточнение пользователя: никаких технических ID, путей, имён модулей и постоянных надписей «демо» / «синтетические данные» на обычных экранах.

Пакет подготовлен 20.11.2026 по `origin/main` = `6f4f7e0cdf6b03d824c835112ee8c010ea9231e1`. Перед реализацией обновить main и проверить актуальные PR; эта привязка описывает исследованный код, а не требует отката.

## Открывать в этом порядке

1. [TASK-GPT-PRO-1.md](TASK-GPT-PRO-1.md) — готовое задание исполнителю.
2. [assets/C3-approved-concept.png](assets/C3-approved-concept.png) — одобренная композиция одного экрана. Это генерация изображения, не приложение и не источник фактов.
3. [reference/workspace.html](reference/workspace.html) — отдельный HTML/CSS-образец того же экрана с последними правками текста. Открывается локально; содержит демонстрационные значения только для оценки оформления, не подключён к API. Поиск и фильтры работают на этих значениях; переходы показывают пояснение о прототипе.
4. [DESIGN.md](DESIGN.md) — размеры, типографика, компоненты, поведение и адаптивность.
5. [DATA-AND-COPY.md](DATA-AND-COPY.md) — отображение настоящих данных и правила продуктового языка.
6. [ACCEPTANCE.md](ACCEPTANCE.md) — приёмка реализации.

Приоритет: последнее требование пользователя → DATA-AND-COPY → DESIGN → HTML-образец → картинка. В исходной картинке остались `reconcile`, S01/S02 и подпись о синтетических данных: НЕ переносить их в обычный интерфейс. HTML уже учитывает это уточнение.

HTML — исполняемый визуальный ориентир, не замена React-приложению. В production нельзя копировать из него вымышленные данные, фиктивные переходы и диалог «это образец». Не вставлять картинку страницы вместо компонентов.

## Содержимое и запуск образца

```sh
python -m http.server 8093 --directory docs/design/c3
# открыть http://127.0.0.1:8093/reference/workspace.html
```

- `reference/tokens.css` — точные начальные переменные системы.
- `reference/workspace.css` / `.js` — композиция и ограниченное поведение образца.
- `assets/Inter-variable.ttf` + `Inter-OFL.txt` — локальный шрифт с лицензией; никакого CDN при запуске.
- `evidence/` — реальные скриншоты HTML-образца и результаты проверки пакета. Они НЕ доказывают готовность приложения.

## Что уже исследовано визуально

- [Apple macOS](https://www.apple.com/os/macos/) и [Numbers](https://support.apple.com/guide/numbers/welcome/mac): масштаб текста, спокойная навигация, разделение фона и содержимого.
- [Linear](https://linear.app/now/behind-the-latest-design-refresh): плотность рабочих списков, слабый визуальный вес навигации.
- [Headroom, референс пользователя](https://headroom-amber.vercel.app/): уверенная типографика, иерархия, ясное основное действие.

Чужие логотипы, изображения и шрифты с ограниченной лицензией не входят в комплект. Основой является собственный C3, а не копирование Apple.

## Графика

Текущему экрану не нужны фотографии. Простые иконки, разделители, скобки расчёта и линия периода — SVG/CSS. Если появится действительно нужная сложная иллюстрация или фотореалистичная деталь, использовать генерацию изображений, а не примитивную SVG-имитацию. Не превращать графику в фон для важных данных; подробности в DESIGN.md.

Для Claude 2 задания в этом пакете нет: пользователь назначит его отдельно.
