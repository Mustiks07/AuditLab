## Рабочий сервер и тестовые ответы

- На настоящем HTTP API проверены выбор запуска, поиск и фильтры, возврат фокуса, сохранение и возврат после перезагрузки, переход из учётного вывода в тот же документ и назад, реальная пара A/B, повтор наблюдений и оценщика. В браузере создана копия со сменой обязательной ссылки. Оценка изменилась с 1/0/0 до 0/1/1 по подтверждённым, ложным и пропущенным находкам. Результат исходной проверки не изменился.
- На том же сервере проверены два изменения времени. Для небольшой контрольной книги сдвиг на две минуты дал остаток 20 000,00 ₸. Для сгенерированной компании перенос последнего зачёта до границы убрал вывод о распределении и сохранил отдельный вывод о дубле. Отдельно открыты отсутствующий запуск и отсутствующая запись.
- Перехватом ответов в браузере проверены пустой каталог, ошибка подключения, отсутствующее подтверждение, запаздывающий ответ при смене проверки, удалённый элемент локального сохранённого, длинное название на 320 px, неизвестное число выводов и отказ проверки. Эти случаи проверяют поведение интерфейса при заданном входе. Закрытые экспорты из браузера по-прежнему ограничены существующим сервером.
- Проверка браузера использует локальный Inter. В журнале зафиксированы ширина viewport и документа, отсутствие внешних HTTP-запросов, ошибок JavaScript и неуспешной загрузки JS, CSS или шрифта. [Машиночитаемый результат](browser-results.json)

## Воспроизведение

Из корня с зависимостями из lock-файлов. Playwright нужен только для отдельной браузерной проверки и не является зависимостью приложения. При использовании уже установленного Playwright можно передать путь к пакету в `C3_PLAYWRIGHT`, а к Chromium — в `C3_CHROME`.

```sh
npm --prefix web ci
npm --prefix web test
npm --prefix web run typecheck
npm --prefix web run build
python -m unittest discover -s tests/foundation -v
python -m unittest discover -s tests/demo -v
python -m auditlab.demo --root artifacts/c3-browser samples
python -m auditlab.demo --root artifacts/c3-browser serve --host 127.0.0.1 --port 8765
# В другом терминале, один раз на свежем каталоге запусков
node web/tests/c3.browser.mjs
```

Скрипт получает исходную пару из метаданных, сохраняет четыре снимка и создаёт отдельные локальные запуски для проверок изменения и пересчёта. Для повтора использовать новый каталог данных. `C3_URL` задаёт адрес локального сервера, `C3_EVIDENCE` — каталог результатов.

Локально использовались Windows, Node.js 24.18.0, Python 3.12.14 и Chromium 158.0.8127.36. Прошли 8/8 frontend-тестов, TypeScript, сборка и 3/3 теста foundation. В CI закреплены Node.js 22 и Python 3.11.14.

Vite складывает рабочую сборку в отслеживаемый каталог `auditlab/demo/static`. В этот же каталог входят локальный файл Inter и его лицензия. Проверка HTTP загружала CSS, скрипт и шрифт из этой сборки. Dockerfile копирует каталог приложения целиком. Холодная сборка нового офлайн-архива и замер её размера на этой ветке не выполнялись.
