# Браузерная приёмка раздела «Исследование»

Настоящие снимки приложения: Chromium без интерфейса, Playwright, `deviceScaleFactor: 2`.
Для репозитория они сжаты до палитры из 256 цветов. Данные на снимках — **фикстура разработки**, а не
измерение эксперимента: компании и документы взяты из открытого набора, действия задал скрипт, оценку
выполнил настоящий оценщик. Подробнее — [RESEARCH_CONSOLE.md](../../../demo/RESEARCH_CONSOLE.md).

## Как повторить

```sh
python -m auditlab.demo --root artifacts/research-browser serve --port 8765 --research-fixtures
```

```sh
node web/tests/research.browser.mjs
```

Playwright берётся вне lock-файла приложения, как в `c3.browser.mjs`. Результат пишется в
`artifacts/research/browser/browser-results.json`. Копия последнего прогона —
[browser-results.json](browser-results.json): 7 групп, ошибок страницы 0, внешних запросов 0, SHA-256
публичных файлов компании B до и после прогона совпали.

## Что проверено

| Группа | Содержание |
|---|---|
| Полный путь, 1440 px | Навигация → эксперименты → эксперимент (модель, варианты, режим, лимиты, прогресс, время, расходы, неактивный запуск с причиной, «Запись эксперимента») → слабость. Ситуация 50 000,00 ₸ / 30 000,00 ₸ / граница 01.12.2026 00:00 не включительно / остаток 20 000,00 ₸. Независимо 20 000,00 ₸, агент 50 000,00 ₸, «Вывод не засчитан». Два неполученных документа; открытие «Зачёт платежа» по точному ключу, дебет 30 000,00 ₸, исходная строка в подробностях. Повтор 3: все документы получены. Сокращённый случай 240 → 8, 20 000,00 ₸, 2 из 2. Семейство: ложные обвинения и сохранившаяся ошибка. Учебный набор: три вида обучения и четыре состояния. Сравнение: «9 из 60», «117 из 120», «31,60 $», интервалы «различие не установлено». Сырые ID в основном тексте отсутствуют |
| Эксплуатационные состояния, 1280 px | Остановка по бюджету, четыре вида неуспешных попыток без оценки, недоступная модель, несуществующий результат |
| Сеть | Отказ соединения, ошибка 500, повтор, устаревший ответ при неудачном обновлении, timeout 15 с |
| Телефон | Пустые данные, очень длинные названия, слабость, сокращение, учебный набор и сравнение на 390 px, слабость на 320 px — без горизонтальной прокрутки |
| Контроллер (перехват API) | Не задан бюджет, отказ `model_unavailable`, принятый запуск, метка «Живой запуск», активная остановка |
| Клавиатура и движение | Ссылка «К содержимому», переход Tab к ссылке доказательства, видимый фокус, Enter открывает документ, фокус переходит на документ; reduced motion обнуляет переходы |
| Неизменность и сеть | Публичные файлы `datasets/open` не изменились, внешних запросов нет, ошибок консоли нет |

Прежний сценарий `web/tests/c3.browser.mjs` на этой сборке тоже проходит: 10 проверок.
