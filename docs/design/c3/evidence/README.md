# Проверка пакета передачи

Это проверка отдельного HTML/CSS-образца C3, не новой реализации AuditLab.

20.11.2026, Chromium через Playwright, локальный HTTP на 127.0.0.1:8093. Перед скриншотами ожидалась загрузка локального Inter (`document.fonts.ready`).

Проверены ширины 1440, 1280, 390 и 320 px: горизонтального переполнения нет. Файлы `workspace-*.png` — full-page screenshots с viewport высотой соответственно 960, 800, 844, 844. Высота картинки может быть больше viewport: содержимое доступно прокруткой, а не уменьшением масштаба.

18 проверок перечислены в `verification.json`: размеры, поиск совместно с фильтрами, пустое состояние и сброс, Ctrl+K, диалог, Escape и возврат фокуса, отсутствие технических названий в основном тексте, reduced motion, загрузка шрифта, отсутствие внешних запросов и ошибок JavaScript. Дополнительно выполнены `node --check` для JS и проверка наличия нужных кириллических символов/₸/стрелки/минуса в font cmap.

Изначальное переполнение мобильной строки исправлено: колонка аудитора явно перенесена в первую колонку мобильной grid-строки. Все перечисленные проверки пройдены после исправления. Скриншоты 1440 и 390 визуально осмотрены.

HTML содержит фиксированные значения для дизайна. Само приложение, реальное API, повтор, пересчёт, безопасность экспорта, CI и offline release этим пакетом не изменялись и не проверялись. Для их проверки предусмотрен `../ACCEPTANCE.md`.
