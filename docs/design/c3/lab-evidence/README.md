# Браузерная приёмка финансовой лаборатории

Снимки сделаны в Chromium без интерфейса через Playwright, `deviceScaleFactor: 2`, и сжаты до палитры
из 256 цветов. Данные — **настоящие опубликованные артефакты**, фикстур среди них нет.

- **Офлайн-репетиция интегратора.** `tools/research_rehearsal.py` на source `988a5db`:
  - поиск и сокращение;
  - 40 попыток встроенных политик;
  - сеть, API-агент и обучение весов не использовались (`not_checked`).
- **Лабораторный прогон.** `tools/financial_lab_rehearsal.py` на рабочем дереве этой ветки:
  - 25 открытых компаний и вариантов;
  - 100 попыток встроенных политик `empty`, `random`, `flag_all`, `reconcile`;
  - 0 сетевых вызовов, 0 вызовов модели.
- **Живой пилот Gemini из репозитория.** Одна завершённая попытка, три с HTTP 429.

Отрицательные состояния получены перехватом ответов API в самом тесте: отмена, ошибка 500, отказ
соединения, устаревший ответ, пустые данные, остановка по бюджету, живой запуск. Они проверяют
интерфейс, а не сервер.

## Как повторить

Команды подготовки данных и запуска сервера — в [FINANCIAL_LAB.md](../../../demo/FINANCIAL_LAB.md).

```sh
C3_URL=http://127.0.0.1:8765 node web/tests/lab.browser.mjs
```

Результат пишется в `artifacts/research/lab-browser/browser-results.json`. Копия последнего прогона —
[browser-results.json](browser-results.json):
- 8 групп пройдено;
- ошибок страницы 0, внешних запросов 0;
- переходы с загрузкой данных: 277–901 мс, медиана 393 мс (локальный сервер, замер агента).

Те же сборки проходят и прежние сценарии:
- `web/tests/research.browser.mjs` на фикстурах — 7 групп;
- `web/tests/c3.browser.mjs` на свежем хранилище примеров — 10 проверок. Повторный прогон на уже
  использованном хранилище падает по таймауту, потому что тест рассчитан на свежее.
