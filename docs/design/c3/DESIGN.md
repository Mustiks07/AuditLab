# C3 — спецификация оформления

## Продукт и визуальная цель

Рабочая среда разработчика аудитора, аналитика и проверяющего. Основные действия: открыть проверку, понять вывод, проследить его до документа, сравнить результаты, повторить опыт и вернуться к сохранённой работе. Показ судьям — один из сценариев.

Светлый спокойный фон, чёткий синий акцент, крупный результат, аккуратные таблицы. Контент важнее интерфейсной рамки. Не использовать тёмный A, рекламный hero, графики ради декора, стекло поверх текста, обилие цветных карточек и гигантские предупреждения.

## Композиция одного главного экрана

Эталон PNG — 1536×1024. HTML-образец — исполняемый ориентир с уточнёнными названиями. Размеры ниже в CSS px при 100% масштабе; не масштабировать страницу через transform.

| Область | Правило |
|---|---|
| Боковая навигация | 232 px на широком экране; спокойная подложка, без внешней рамки. Активный пункт — лёгкая синяя заливка и тонкая метка. |
| Основная область | Отступы 32 px; при ширине более 1600 — максимум контента 1320 px, без растягивания таблицы до бесконечности. |
| Верхняя служебная строка | Хлебные крошки слева, поиск справа; высота около 40 px. |
| Заголовок | 38–42 px/1.12, вес 700; основной CTA справа; отступ до содержимого 28–32 px. |
| Продолжение проверки | Две трети верхней строки, минимум около 600 px; компания → результат + расчёт → подтверждение и переход. |
| Сравнение | Одна треть верхней строки, минимум 280 px; компактные A/B и временная граница только при наличии этих данных. |
| Последние запуски | На всю ширину под карточками. Заголовок 26–30 px, фильтры, таблица 56–60 px/строка. Никакой внешней рамки-карточки. |

Не закреплять все блоки по высоте окна: при длинном содержимом страница прокручивается. Не обрезать кнопки и не прятать строки за нижней панелью. Не требовать пяти строк, если API вернул другое количество.

## Типографика и tokens

Локальный Inter Variable, лицензия OFL приложена. Картинка генерации не гарантирует точного шрифта; шрифт из пакета является решением для реализации. Основные веса 400/500/600/700, не искусственный bold. Font-display: swap. UI 15 px/1.5, подписи 13 px/1.45, заголовок страницы 40 px, секции 28 px, карточки 22 px, основной финансовый результат 48 px. На 1280 можно снижать заголовок до 36, сумму до 40, но не основной текст ниже 14. На мобильном заголовок 30, сумма 36. Денежные значения: tabular-nums, no-wrap по возможности, знак валюты в той же строке.

Цвета, отступы, радиусы, focus и motion заданы в `reference/tokens.css`. В реальном приложении вынести в единый слой переменных. Акцент `#3154E8`; основной текст `#172033`; вторичный `#606B80`; светлая поверхность `#FFFFFF`; фон `#FAFBFD`; бордер `#DFE4ED`; выделение `#EDF2FF`; подтверждение `#176A48`; предупреждение `#96500D`; ошибка `#B53F29`. Проверить фактический контраст в конечных компонентах.

## Компоненты и поведение

- **Sidebar:** обычные ссылки, aria-current на текущей; иконка 20 px, штрих 1.7–1.9 px. Крупный логотип только вверху. «Локально» допустимо как характеристика развёртывания, не фиктивный статус доступности сервера.
- **Button:** высота 44 px, горизонтальные поля 16–20; blue primary, нейтральный secondary, текстовые переходы. Disabled различим; pending предотвращает дублирование операции и показывает её ход. Знак «+» из исходного PNG заменить на открытие/папку, поскольку действие открывает существующий запуск.
- **ContinueReview:** последняя доступная просмотренная проверка из local state; иначе детерминированный доступный запуск. Заголовок не заявляет «продолжить», если никто ещё не открывал проверку: тогда «Выбранная проверка». Несколько выводов не сводить к общей сумме без смысла: показывать выбранный вывод и «ещё N».
- **MiniCalculation:** рисунок скобки заменяет только соединительную линию. Суммы и подписи остаются обычным текстом DOM. Формула — из derivation, не универсальное `поступило − распределено` для любого типа ошибки. При неподдерживаемом типе — соответствующий краткий расчёт либо ссылка на подробности.
- **PairPreview:** только реальная пара; A/B определять по pair_role, а не случайной сортировке ID. Не всегда рисовать временную границу: произвольная пара может отличаться суммой/валютой/иным фактом. Для неописанного изменения нейтральный текст «Сравнение выбранных запусков».
- **RunsTable:** цель строки — открыть запуск; отдельные кнопки внутри не должны давать двойную навигацию. Заголовки настоящие th, сортировка по кнопке с aria-sort. Политика — человеческая подпись. Поиск и фильтры комбинируются; после очистки возвращаются все результаты. Полный список доступен, последние строки не подменяют весь каталог.
- **Search:** одинаковое ожидаемое поведение у поля и Ctrl/Cmd+K; не перехватывать ввод в чужом диалоге. Простой поиск по названиям/периоду/политике достаточен, не нужна имитация AI-поиска.
- **Documents / Saved:** настоящая навигация по выбранному запуску и локально сохранённым ссылкам. Не генерировать отдельные названия документов с несуществующими номерами. Для отсутствующего контекста — понятный выбор запуска.

## Состояния

| Случай | Отображение |
|---|---|
| Загрузка | Skeleton, сохраняющий геометрию; aria-busy. Не показывать 0 как загруженное значение. |
| Нет запусков | «Пока нет проверок» и ясная помощь по подключению данных; CLI-инструкция только в раскрываемой технической помощи, не главный текст экрана. |
| Нет совпадений | «Ничего не найдено», очистить фильтры. |
| Сеть недоступна | «Не удалось подключиться к сервису проверок», повторить. Не показывать сырой stack/API path. |
| Отсутствует документ | «Документ недоступен», назад к проверке. |
| Сверка не подключена | «Независимая сверка не выполнена», нейтральный цвет. |
| Сбой/усечение | Соответствующее сообщение, незавершённость явно сохранена; нет автоматического зелёного «без расхождений». |

## Адаптивность и доступность

≥1440: две верхние области, полный sidebar. 1100–1439: sidebar 208, внешние поля 24, суммы 40. 768–1099: верхние области друг под другом при недостатке места, навигация сворачивается, содержимое не сжимается до микротекста. <768: кнопка меню с подписанным диалогом/панелью, focus trap + Escape + возврат фокуса; карточки и формула вертикально; таблица превращается в доступный список с теми же данными и действиями. На телефоне главная кнопка видна, строки можно открыть пальцем, минимальная цель 44 px. Проверить 390 и 320 px.

Нельзя скрывать статус ошибки ради компактности. Цвет всегда дополнен текстом/значком. Focus-visible 3 px с отступом. Не кодировать выбор только hover. Анимация hover/focus 120–160 мс; раскрытие 180–220 мс; reduced-motion отключает перемещения. Финансовые числа не анимировать счётчиком.

## Графика и шрифты

Простые иконки и знак AuditLab делать в SVG; геометрия в одном стиле. Включённые в HTML SVG — исходные простые пиктограммы, разрешено довести их оптически. Не использовать растровые иконки и чужие логотипы Apple/Linear.

Генерация нужна только для сложного иллюстративного объекта/фото, если он помогает конкретному сценарию и его невозможно качественно выполнить простым вектором. Сейчас такого места на главном экране нет. Для будущего ассета: записать назначение, промпт, исходный PNG, версии WebP/AVIF при необходимости, размеры 1×/2×, alt/декоративность, локальный путь и сведения о происхождении. Прозрачный фон запросить явно, если нужен вырезанный объект. Реальные финансовые документы нельзя заменять сгенерированными «доказательствами». Таблицы, подписи, текст кнопок и формулы всегда живые компоненты.
