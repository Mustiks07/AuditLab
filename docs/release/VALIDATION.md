Цель — сильная конкурсная среда с доказуемой финансовой корректностью и воспроизводимым запуском. Победа и баллы закрытых испытаний не выводятся из внутренних тестов.

## Историческая матрица до PR #28/#22 и генератора 1.5: SPEC §14

На исходном a301b16 при проверке работ 20 ноября был найден блокер (впоследствии исправлен в PR #28):
[#23](https://github.com/Mustiks07/AuditLab/issues/23). Синтаксически корректный
JSON `submit` с `findings` глубины 600 срывает финализацию runner: состояние
`done`, `final=None`, пустая траектория и исключение вместо результата. Проверено
через внешний JSONL-процесс на Python 3.11.14. Это существующий дефект, который
успешная репетиция обычных политик не покрывает. До исправления API-03/API-04
и MAT-03 нельзя считать полностью принятыми. Опубликованный RC2 остаётся
историческим кандидатом; его успешные измерения не отменяют этот контрпример.

«Покрыто» — имеются конкретные успешные внутренние испытания, а не сертификат организатора. Общий строгий `run.py verify --suite rehearsal` сохраняет exit 2, пока полная приёмка не закрыта; отдельный checker подтверждает только исполняемые внутренние 20/80/20 и ресурсы.

## Независимые проверки и исправления

[Ручные финансовые материалы](../reviews/manual-financial/README.md) подтверждают шесть находок по public, отдельный чистый возврат и 78 адресуемых evidence-ссылок. Их исходные train/dev сохранены побайтно. Новый профиль 1.1 публикует исключающую границу и версии правил, содержит явно проверенный полностью чистый возврат.

В PR #12 исправлены DST-расчёты, валютные единицы/сопоставление консоли, недопустимые counterfactuals, транспорт/deadline/cleanup, malformed truth и ложное подтверждение replay по одному публичному нулевому reward. Версии: generator 1.3, runner/evaluator 1.1, verifier-rules 1.1, tzdata 2026.6.

Текущее оставшееся действие по #15: передать опубликованный RC4 независимому
человеку и сохранить его фактический журнал приёмки. Официальные результаты жюри и сравнение с другими командами остаются
неизвестными независимо от внутреннего F1.
