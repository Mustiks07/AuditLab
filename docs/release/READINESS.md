# Готовность RC5 к проверкам Genesis

Состояние сверено 22 ноября 2026 года. Код RC5 опубликован; итоговая внешняя приёмка
ещё не завершена. Этот документ отделяет проверенную реализацию от результатов,
которые может выдать только жюри или независимый получатель.

## Опубликованные определения

Повторно скачан [действующий текст Genesis](https://genesis-exe.com/docs/fintech-checks.txt).
SHA-256 `2a597ebfb94daec700ba9b1b09d62c032366e788c6e992486d444e063be8d870`
совпадает с определениями, использованными нашим стендом. Изменений правил не обнаружено.
[Машиночитаемая квитанция](evidence/genesis-readiness-2026-11-22.json) связывает
сверку с точными коммитами и CI. Подтверждённый main: `ba085f0456ffb8993553ed8c5e3c29dbd8f4f5ab`.
Последующие изменения этого отчёта не являются новым измерением кода.

| Проверка на нашем стенде | Результат |
|---|---:|
| Контракт адаптера, действия, режимы и ограничения | 20/20 |
| Данные, включая дополнительную проверку транспорта | 21/21 |
| Опубликованные векторы награды | 20/20 |
| Парные проверки порядка и ID | 20/20 |
| Примеры matcher | 15/15 |
| Дополнительные отрицательные случаи | 13/13 |
| CI проекта на проверенных head/base | 721 тест, без провалов и пропусков |

Эти количества не складываются в конкурсный балл. Фикстуры нашего стенда созданы
по опубликованным определениям; закрытые seed и прогон организаторов нам недоступны.
Пять инженерных критериев жюри также не оцениваем за него: запуск и версии описаны
в [инструкции получателя](../demo/HANDOFF.md), траектории и измерения — в
[отчёте выпуска](VALIDATION.md), разбор ограничений — в
[интеграционной приёмке](../reviews/hardening-v3-integration/REPORT.md).

В CI теперь обязательны полный стенд Genesis и независимые преобразования ID.
В пяти корректных профилях преобразований прошли 24/24 исторических и 20/20 новых
открытых эпизодов. Неполные преобразования, оставляющие оборванные ссылки, отдельно
диагностируются; это не выдаётся за дефект неизвестного преобразования жюри.

## Что получает жюри

[Релиз v0.1.0-rc.5](https://github.com/Mustiks07/AuditLab/releases/tag/v0.1.0-rc.5)
содержит офлайн-архив, контрольные суммы, отчёт и свидетельства проверки.
Код: `920b251ee3b1c12f9bc5ffe0eca3b5cb1bf8d78a`; код проверенного main совпадает с RC5.
Точки подключения `generate_episode`, `make_env`, `score_episode` находятся в
`judge_adapter.py`, внутри runtime-контейнера — `/app/judge_adapter.py`.
[Контракт и запуск адаптера](../GENESIS_ADAPTER.md).

Офлайн-архив: 427 249 789 байт, SHA-256
`d2cb2723ab2b493376c9d9b8620e7d29968d8c56318fcace5f6eaacdc4578641`.
На каждом из двух свежих хостов Docker (classic и containerd) прошли 528 тестов,
80 попыток четырёх политик и 20 пар. Это повтор одного набора из 20 эпизодов профиля
1.1 на двух конфигурациях, а не 40 независимых компаний и не результат профиля 1.3.
Новый профиль отдельно проверен на 20 открытых и 20 сценарных эпизодах.

Для показа подготовлены [сценарий защиты](../demo/DEFENSE.md), интерфейс,
доказательства, пересчёт, изменение факта и резервный повтор записи.
Запись агентской репетиции не заменяет выступление команды или человеческую приёмку.

## Оставшиеся внешние проверки

| Пункт | Состояние и точное условие закрытия |
|---|---|
| Память всей машины для RC5 (OPS-01) | Не проверено. Нужен повтор именно RC5 на Linux/WSL VM с 2 CPU, не более 4 000 000 000 байт выделенной RAM, без swap; журнал памяти ОС и Docker. Исторический успешный замер RC3 не переносится на RC5. Контейнерные лимиты RC5 суммарно 3 GiB не доказывают лимит всей машины. |
| Независимый получатель (OPS-02) | Не проверено. Человек вне реализации скачивает RC5 и проходит HANDOFF без установки пакетов проекта и помощи авторов, сохраняет команды, коды, журнал и наблюдения по UI. [Issue #15](https://github.com/Mustiks07/AuditLab/issues/15). |
| Улучшение ИИ-аудитора | Не измерено: нужен завершённый сопоставимый A/B/C и независимый пересчёт. Работа API сама по себе не доказывает качество. |
| Финальный закрытый набор | Архив 90 семейств/180 вариантов получен и проверен по хешам; финальных запусков 0. Запуск один раз после фиксации агента. В наборе остаются 10 неподготовленных граничных слотов; они не считаются пройденными. |
| Официальный балл | Неизвестен до проверки организаторов. |

Строгая полная приёмка пока возвращает `incomplete`/код 2; успешный внутренний checker
не отменяет отсутствующих внешних свидетельств. Для RC5 менять этот статус на
«полностью принято» без нового журнала нельзя.
